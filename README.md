# Yearly Income Estimator

A free, single-page tool that turns monthly income into a yearly estimate. Add as many lines as you need, tag each one as Taxed or VA, and the totals update as you type. Works on phones, prints clean on letter paper, and supports dark mode.

**Private by design:** everything runs in the browser. Nothing is saved, stored, or sent anywhere.

## Files
- `index.html` - the whole app (HTML, CSS, JS in one file)
- `render.yaml` - Render static site config

## Deploy on Render
1. Upload these files to a new GitHub repo (Add file > Upload files).
2. In Render: New > Static Site > pick the repo.
3. Build command: leave blank. Publish directory: `.`
4. Create Static Site. Every push to `main` redeploys automatically.

Estimate only, not tax or financial advice.
